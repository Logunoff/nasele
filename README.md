# nasele

Система для управления коттеджным поселком.

## О проекте

nasele помогает организовать работу поселка: распределить ответственность между участниками, вести учет участков и собственников, наладить взаимодействие между управлением поселка и жителями.

## Ролевая модель

Доступ к функциям системы определяется ролью пользователя.

| Роль | Описание |
| --- | --- |
| **Владелец поселка** | Верхний уровень управления. Видит всю информацию по поселку, назначает управляющих, принимает ключевые решения. |
| **Управляющий** | Ведет повседневное управление поселком: участки, собственники, задачи для персонала. |
| **Персонал** | Сотрудники, выполняющие работы в поселке. Получают и выполняют назначенные задачи. |
| **Собственник участка** | Житель или владелец участка. Видит информацию по своему участку и взаимодействует с управлением поселка. |

## Статус

Проект на ранней стадии: идет проектирование. Стек и структура репозитория будут описаны по мере разработки.
